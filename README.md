# Варіант 2: Система пошуку книг (Мікросервісна архітектура)

Цей проєкт реалізовано на **TypeScript + Node.js (Express)** відповідно до завдання практичної роботи.

## Архітектура

- **`book-service/`** (порт `5001`): Web API мікросервіс. 
  - Звертається до зовнішнього постачальника (OpenLibrary API).
  - Нормалізує потік даних і повертає DTO у форматі JSON (`title`, `author`, `year`, `isbn`).
  - Обробляє помилки (400, 404, 502).
- **`book-web/`** (порт `3000`): Клієнтський вебзастосунок (MVC на Express + EJS).
  - Звертається виключно до `book-service` через HTTP API.
  - Надає інтерфейс пошуку та відображає книги у вигляді карток.
  - Обробляє помилки недоступності мікросервісу.

---

## Інструкція запуску

Відкрийте **два окремі термінали**:

### Термінал 1: Запуск API-сервісу (`Book.Service`)
```bash
cd book-service
npm run dev
```
Сервіс запуститься на `http://localhost:5001`.  
Перевірка через браузер/curl: `http://localhost:5001/api/books?query=Clean%20Code`

### Термінал 2: Запуск вебклієнта (`Book.Web`)
```bash
cd book-web
npm run dev
```
Клієнтський інтерфейс буде доступний за адресою:  
👉 **http://localhost:3000**

## Сценарії перевірки для викладача

1. **Успішний пошук**: Введіть `Clean Code` або `Martin Fowler` -> отримаєте список карток з автором, роком і ISBN.
2. **Книгу не знайдено**: Введіть випадковий набір символів (наприклад, `qwerty12345xyz`) -> отримаєте повідомлення `За запитом "..." нічого не знайдено.` (код 404 від сервісу).
3. **Недоступність сервісу (демонстрація мікросервісної відмовостійкості)**: 
   - Зупиніть сервіс у Терміналі 1 (натисніть `Ctrl + C`).
   - Спробуйте зробити пошук на сторінці `http://localhost:3000`.
   - Побачите попередження: `Book.Service недоступний. Перевірте, чи запущено мікросервіс.`
